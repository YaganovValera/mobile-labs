## Как проверить POST_NOTIFICATIONS на Pixel 6 API 35

### Выдача разрешения

1. Установите/запустите приложение.
2. Откройте незавершённую задачу и нажмите «Выполнено» (первый раз).
3. В системном диалоге выберите **Разрешить**.
4. Проверьте шторку уведомлений: заголовок «Задача выполнена», текст — название задачи.
5. Альтернатива через adb:
   ```bat
   adb shell pm grant com.example.mobilelab01 android.permission.POST_NOTIFICATIONS
   ```

### Отзыв разрешения

1. Настройки Android → Приложения → Менеджер задач → Уведомления → отключить.
2. Или через adb:
   ```bat
   adb shell pm revoke com.example.mobilelab01 android.permission.POST_NOTIFICATIONS
   ```
3. Завершите другую незавершённую задачу.
4. Ожидание: статус сохраняется; уведомления в шторке нет; при уже запрошенном ранее разрешении показывается snackbar «Задача сохранена, но уведомления отключены».

### Сброс признака «уже спрашивали»

Чтобы снова увидеть системный диалог разрешения:

```bat
adb uninstall com.example.mobilelab01
adb install app\build\outputs\apk\debug\app-debug.apk
```

Либо очистить данные приложения в настройках Android.

## Замечания

- Первый показ системного диалога разрешения при пользовательском действии в автоматическом прогоне заменён на `pm grant` / `pm revoke` + сохранённый флаг запроса; ручная проверка диалога описана выше.
- Нажатие по уведомлению должно открывать `MainActivity` (PendingIntent); отдельный UI-клик по уведомлению в этой сессии не автоматизировался — логика задана в коде.
