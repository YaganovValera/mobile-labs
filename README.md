# Mobile Labs

Лабораторные работы по дисциплине «Разработка мобильных приложений».

## Менеджер задач (ЛР №1–2)

Android-приложение для управления задачами, последовательно разработанное в двух лабораторных работах.

**ЛР №1 — Интерфейс и навигация:**

- Главный экран со статистикой, список задач, карточка задачи и форма создания/редактирования.
- Изменение статуса, проверка ввода и переходы между экранами.

**ЛР №2 — Локальные данные и REST API:**

- Хранение задач в Room (SQLite) между запусками приложения.
- Создание, просмотр, редактирование и удаление задач с подтверждением.
- Отдельный экран задач из [JSONPlaceholder](https://jsonplaceholder.typicode.com/todos) через REST API.
- Индикация загрузки, сообщения о сетевых ошибках и повторный запрос.

**Технологии:** Kotlin, Jetpack Compose, Material 3, Room, Coroutines/Flow, Retrofit.
