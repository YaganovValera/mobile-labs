# Mobile Labs

Лабораторные работы по дисциплине «Разработка мобильных приложений».

## Менеджер задач (ЛР №1–3)

Android-приложение для управления личными задачами, последовательно доработанное в трёх лабораторных работах.

**ЛР №1 — Интерфейс и навигация**

- Главный экран со статистикой, список задач, карточка задачи и форма создания/редактирования.
- Переключение статуса, проверка ввода и навигация между экранами.

**ЛР №2 — Локальные данные и REST API**

- Хранение задач между запусками в Room (SQLite).
- Создание, просмотр, редактирование и удаление задач с подтверждением.
- Загрузка задач из [JSONPlaceholder](https://jsonplaceholder.typicode.com/todos) через REST API на отдельном экране.
- Индикация загрузки, обработка сетевых ошибок и повторный запрос.

**ЛР №3 — Уведомления и тестирование**

- Локальное Android-уведомление при отметке задачи выполненной.
- Запрос разрешения `POST_NOTIFICATIONS` на Android 13+ и корректная работа при отказе.
- Проверка основных сценариев приложения на эмуляторе Pixel 6 (API 35); тест-кейсы — `MobileLab01/LAB3_TEST_CASES.md`.

**Технологии:** Kotlin, Jetpack Compose, Material 3, Room, Coroutines/Flow, Retrofit, Android Notifications.

## Запуск

1. Открыть папку `MobileLab01` в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить приложение на эмуляторе или устройстве Android (минимальная версия — API 26).

Для сборки debug APK из каталога `MobileLab01` в Windows:

```powershell
.\gradlew.bat assembleDebug
```

Результат: `MobileLab01/app/build/outputs/apk/debug/app-debug.apk`.
