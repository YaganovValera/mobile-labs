# Mobile Labs

Лабораторные работы по дисциплине «Разработка мобильных приложений».

## Лабораторная работа №1 — Менеджер задач

Android-приложение для управления личными задачами.

**Реализовано:**
- Главный экран со статистикой задач.
- Просмотр списка и подробной информации о задачах.
- Создание и редактирование задач.
- Изменение статуса выполнения.
- Навигация между экранами и проверка вводимых данных.

Данные хранятся в памяти приложения без использования базы данных.

**Технологии:** Kotlin, Jetpack Compose, Material 3.

**Среда разработки:** Android Studio, Android Emulator (Pixel 6, API 35).
